Abra front/index.html no navegador para jogar e apresentar.
Leia APRESENTACAO.md para seguir o roteiro e demonstrar as regras.
Leia LEIA-ME.md para entender a organização dos arquivos.

Após editar back/damas.js, execute na pasta do projeto:
node front/scripts/atualizar-aula.cjs

Para verificar as regras com Node.js:
node --test back/testes/damas.test.cjs

O jogo abre sem instalar dependências. A versão atual usa JavaScript, HTML e CSS.
